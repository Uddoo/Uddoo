## Selected projects

### [TrafficMonitor-Codex-Plugin](https://github.com/Uddoo/TrafficMonitor-Codex-Plugin)

**Codex usage, right in the Windows taskbar.** See remaining quotas at a glance and hover for reset times and token usage details.

把 Codex 用量放进任务栏：一眼查看剩余额度，悬停查看重置时间与 Token 明细。

**C++ · Python · Windows**  
[Taskbar & tooltip screenshots](https://github.com/Uddoo/TrafficMonitor-Codex-Plugin#截图--screenshots) · [Download](https://github.com/Uddoo/TrafficMonitor-Codex-Plugin/releases)

### [mihomo-smart-selector](https://github.com/Uddoo/mihomo-smart-selector)

**Compare nodes for the service you actually use.** Run service-specific probes, compare candidates with your current node, and explicitly confirm a switch.

按服务探测节点：查看排名与样本，对比当前节点和候选，再确认切换。

**Go · Vue · SQLite**  
[Probe results & node comparison](https://github.com/Uddoo/mihomo-smart-selector#showcase) · [Try the local demo](https://github.com/Uddoo/mihomo-smart-selector#quick-start)

### [transit2fog](https://github.com/Uddoo/transit2fog)

**Turn journeys you've taken into map traces.** Enter metro or rail journeys, preview and confirm the route, then export GPX for Fog of World and other compatible apps.

把实际坐过的地铁和火车变成足迹：录入行程、预览并确认线路、导出 GPX。

**Local journey storage · Route previews · GPX export**  
[Watch the journey-to-GPX demo](https://github.com/Uddoo/transit2fog#从选站到导出) · [Getting started](https://github.com/Uddoo/transit2fog/blob/main/docs/GETTING_STARTED.md)
